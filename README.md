## ▶️ How to Run

1. Install **XAMPP**.
2. Clone this repository or copy it into:

```text
C:\xampp\htdocs\
```

3. Start **Apache** (and **MySQL** if required).
4. Open your browser:

```text
http://localhost/wfs-practical/
```

5. Open the required topic folder to run the practical.
